# Historical records

- [Legacy results](legacy_results/) preserve the earlier `results/` tree. The original
  internal directory names and substantive files are retained to preserve provenance
  and relative references in the historical scripts.
- [Previous file manifest](previous_file_manifest.csv) preserves the manifest that
  accompanied `current_revision_data/` before the reorganization. Of its 411 entries,
  62 describe CRLF text files before Git normalized them to LF. The current manifest
  is [data/validation/file_manifest.csv](../data/validation/file_manifest.csv).
- [Previous repository README](https://github.com/Shihaoling/raw-and-processed-data/blob/4211439c4ae4225932b5f8f3f531a152410364fd/README.md) retains the older result
  tables in their original repository context.
